# Course Eligibility Checker

A simple and responsive web application developed using **HTML**, **CSS**, and **JavaScript** that checks whether a student is eligible for a selected course based on their percentage.

---

## 📌 Project Description

This project allows users to enter:

- Student Name
- Percentage
- Course Selection

The application then checks eligibility according to predefined criteria and displays the result instantly.

---

## 🚀 Features

- Simple and clean interface
- User-friendly design
- Input validation
- Instant eligibility checking
- Built using pure HTML, CSS, and JavaScript
- No external libraries required

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## 📋 Eligibility Criteria

| Course | Minimum Percentage |
|---------|-------------------|
| Engineering | 75% |
| Medical | 85% |
| Management | 60% |
